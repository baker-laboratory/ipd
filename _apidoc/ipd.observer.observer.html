ipd.observer.observer module#

Observer pattern implementation for method dispatch in the IPD framework.

This module provides a dynamic event dispatch system using a centralized Subject instance (hub) and auto-registered singleton observer classes derived from Observer.

The key idea is that calling hub.some_method(…) dispatches the call to all registered observers that define a method named some_method.

Use cases include debug reporting, instrumentation, UI hooks, and logging.

class MyObserver(Observer):
    def set_config(self, conf):
        self.conf = conf

    def event_happened(self, info, methodname=None):
        print("Received:", info)

hub._debug = True
hub.event_happened("hello")
# Output (example):
# === Observer Warnings ===
# no observers have registered for shutdown. all methods registered: {...}
# =========================

print(hub.usage)
# {'event_happened': ['MyObserver']}
class ipd.observer.observer.Observer(*args, **kw)[source]#

Bases: ABC

Base class for observer components that hook into the hub.

Subclasses are instantiated once and auto-registered. Must define a set_config() method to configure themselves.

Instances are accessible via hub[MyObserver] or MyObserver().

Example:

class Logger(Observer):
    def set_config(self, conf):
        self.conf = conf

    def debug(self, msg, name=None, lvl=0, methodname=None):
        print(f"{name}: {msg}")

class ipd.observer.observer.ObserverMethod(subject, method, **kw)[source]#

Bases: object

Proxy for a method call on a Subject. Dispatches to all observers.

This class is returned when accessing hub.methodname. When called, it checks which observers implement that method, and calls it on each of them.

Handles special case logic (e.g. for debug, set_config, shutdown).

Warning

This proxy does not return a combined result — only a list of individual results.

Parameters:

  • subject (Subject) – The subject owning the observers

  • method (str) – The method name to proxy

  • kw (dict) – Default keyword arguments to merge into call

class ipd.observer.observer.Subject(conf=None)[source]#

Bases: object

Central registry and dispatch controller for all Observer instances.

The singleton hub instance of this class controls observer registration and method dispatch. Calling hub.foo() will forward the call to all observers that implement foo.

Debug-related calls are filtered using regex and level settings stored in conf.viz (a Hydra/OmegaConf config).
